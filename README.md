# Look de Quince

Número 01 de la revista para chavas de nivel C y C+. Next.js 16.3, TypeScript, Postgres de Vercel (Neon) y Blob para las fotos de eventos.

Sin `POSTGRES_URL` y `BLOB_READ_WRITE_TOKEN` el número se ve igual: los looks y las fiestas de muestra viven en el repo. La subida real espera a que el store esté conectado.
